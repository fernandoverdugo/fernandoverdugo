# Fernando Verdugo

I build data and AI projects focused on **public programs, policy, operations, and decision support**.

My background in public-service program administration and regulatory work informs the questions I choose to analyze: how programs perform, where access gaps exist, how policy changes can be evaluated, how limited resources can be allocated, and how data systems can make complex information easier to use.

My portfolio combines **SQL, Python, statistical analysis, machine learning, causal inference, forecasting, geospatial analytics, optimization, and applied AI**.

## Featured Work

### SQL & Operational Analytics

**[Service Operations SQL Analytics](https://github.com/fernandoverdugo/service-operations-sql-analytics)**  
Relational SQL analysis of simulated public-service operations covering referrals, cases, appointments, service delivery, conversion funnels, SLAs, cohorts, repeat utilization, and management KPIs.

[Live dashboard](https://fernandoverdugo.github.io/service-operations-sql-analytics/dashboard.html)

**[Public Program Compliance Monitoring & Risk Analytics](https://github.com/fernandoverdugo/public-program-compliance-risk-analytics)**  
SQL and Python compliance-monitoring system for a simulated regulated program, combining provider scorecards, corrective-action monitoring, exception detection, temporal risk modeling, and review-capacity analysis.

### Policy & Program Evaluation

**[Medicaid Unwinding & Healthcare Access](https://github.com/fernandoverdugo/medicaid-unwinding-healthcare-access-causal-analysis)**  
State-level causal policy evaluation using CMS and Census data, continuous-exposure difference-in-differences, event-study diagnostics, clustered inference, placebo testing, and robustness analysis.

[Live policy dashboard](https://fernandoverdugo.github.io/medicaid-unwinding-healthcare-access-causal-analysis/)

**[SIPP Economic Stability & Poverty Transitions](https://github.com/fernandoverdugo/sipp-economic-stability-analysis)**  
Longitudinal Census analysis measuring poverty entry and exit using SIPP panel data, replicate-weight inference, household-linked observations, and prospective modeling.

**[NHIS Healthcare Access Analysis](https://github.com/fernandoverdugo/nhis-healthcare-access-analysis)**  
National analysis of cost-related delayed medical care using complex-survey inference, multiple imputation, predictive modeling, calibration, and subgroup diagnostics.

### Forecasting & Decision Support

**[NYC 311 Service Demand Forecasting](https://github.com/fernandoverdugo/nyc-311-service-demand-forecasting)**  
Time-series forecasting of more than 16 million NYC 311 requests using rolling-origin validation, statistical and machine-learning benchmarks, uncertainty analysis, and workload planning.

[Live dashboard](https://fernandoverdugo.github.io/nyc-311-service-demand-forecasting/)

**[Refugee Resettlement Capacity & Resource Planning](https://github.com/fernandoverdugo/refugee-resettlement-capacity-planning)**  
Forecasting and optimization platform for refugee-arrival demand, staffing capacity, service coverage, constrained resource allocation, and scenario planning.

[Live planner](https://refugee-resettlement-capacity-planner.onrender.com)

### Geospatial Analytics

**[Texas Afghan Support Program — Geospatial Analytics](https://github.com/fernandoverdugo/texas-afghan-support-geospatial-analytics)**
